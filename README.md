# DEADLOCK 2026 – Autonomous Agent

An autonomous C++20 agent developed for the DEADLOCK 2026 competition using the official participant SDK.

## 🚀 Project Overview

This repository contains the source code of my DEADLOCK 2026 agent, developed in C++20.

The agent is designed to make intelligent decisions based on the game environment, navigate the available paths, evaluate potential risks, and select suitable actions.

## 🛠️ Tech Stack

- **Language:** C++
- **Standard:** C++20
- **SDK:** DEADLOCK Participant SDK
- **IDE:** Visual Studio Code
- **Version Control:** Git & GitHub

## 🧠 Agent Implementation

The current implementation includes:

- Pathfinding and navigation logic
- Cost-based path evaluation
- Danger-aware movement decisions
- Goal selection
- Dynamic decision-making based on the environment

## ⚙️ Development

1. Download the official DEADLOCK 2026 Participant Kit.
2. Set up the required C++20 development environment.
3. Configure the participant SDK.
4. Integrate the agent source code.
5. Compile and execute using the official competition instructions.
